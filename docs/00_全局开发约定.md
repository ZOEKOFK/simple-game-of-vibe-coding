# 全局开发约定（Agent 记录 · 后续所有开发必须遵守）

> 本文档由 Agent 在项目启动时记录，作为整个开发过程的强制约束基线。若与后续文档冲突，以开发者的最新指示为准。

## 项目背景

- 项目名称：《竞技场幸存者》（Arena Survivor），俯视角竞技场生存射击游戏。
- 玩法定位：Roguelite 随机生成机制 + 自动战斗（割草）玩法，参考《土豆兄弟》《Hall of Torment》。
- 核心玩法循环：按波次生成敌人 → 玩家键盘移动走位规避 → 武器自动瞄准攻击 → 击杀得经验 → 升级时随机三选一（装备/属性增益）构建本局能力 → 尽可能存活更多波次。

## 技术栈（强制）

- 语言 C++20；构建 CMake 3.20+；包管理 vcpkg（manifest 模式，vcpkg.json）。
- 图形库 raylib 4.x（vcpkg 安装）；若失败降级 SDL2 + SDL_image + SDL_mixer，并主动告知开发者。
- 目标平台 Windows 10/11；生成器（Visual Studio 或 MinGW）由 Agent 自行决定并完成配置。

## 目录结构（强制）

```
docs/    （需求分析、系统分析、系统设计、开发计划及本约定文档）
src/     （源代码，按功能分多个 .h/.cpp 文件）
assets/  （音效、字体等资源，非强制）
README.md
```

## 代码风格（强制）

- 面向对象、模块清晰、单一职责、易扩展（为加武器/加词条预留接口）；
- 关键代码写中文注释；
- 常量集中在统一头文件（constants.h）定义，禁止散落硬编码。

## 开发流程铁律（强制）

1. 绝不一次性生成整个游戏；每步只完成当前提示词要求的子任务。
2. 每个子任务完成后必须输出《验收清单》：编译/启动方式、操作步骤、预期现象，供人工测试。
3. 收到问题反馈时只修改问题相关部分，绝不推翻已验收功能、不大规模重构。
4. 每完成一个子任务用 git 提交一次（环境无 git 则告知开发者并跳过）。
5. 除明确要求外不擅自添加功能，避免功能蔓延。

## 模块划分蓝图（待开发者确认）

1. 游戏框架：GameEngine 固定时间步主循环 + 五状态状态机（主菜单/进行/暂停/升级选择/结算）
2. 玩家：八方向移动（对角归一化）、Stats 属性中心、受击无敌帧与击退
3. 敌人：Enemy 抽象基类 + 爬行者(追踪) / 喷吐者(保持距离射击) / 蛮牛(蓄力冲锋) 差异化 AI
4. 武器：Weapon 抽象基类自动索敌（射程内最近敌人），子类实现开火模式（手枪/霰弹/环绕飞刃）
5. 波次：WaveManager 状态机（休整→小批量刷怪→清场）+ EnemySpawner（边缘出生、远离玩家）
6. 升级词条：经验吸取 → 升级暂停三选一 → 稀有度权重抽取 → 词条以"修改 Stats"方式生效
7. 碰撞：圆-圆检测 + 空间哈希网格分区，支撑同屏 200+ 敌人 60 FPS
8. UI：HUD（血条/经验/波次/击杀）+ 升级面板 + 结算面板，屏幕空间绘制、与逻辑解耦
